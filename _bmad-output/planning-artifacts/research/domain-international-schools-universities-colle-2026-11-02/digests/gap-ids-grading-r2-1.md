## Contradictions / surprises
- Emirates ID "YYYY" block is not reliably birth year — do not derive DOB from it in seed validation.
- QUT (and likely other Australian unis) has no "N" grade; uses 1–7 numeric with "Marginal Fail" (3, 40–49%). HD/D/C/P/N letter scheme is institution-specific.
- NUS has renamed CAP to GPA; honours bands confirmed for HD/D/Merit/Honours; Pass band unconfirmed.
- Malaysia First Class cut-off is 3.67 per commercial sites but UM's official handbook uses 3.70 for its top category — varies by university.
- India: PEN (student) and UDISE+ school code are both 11 digits — easy to conflate. PEN expansion inconsistently given as "Permanent Education Number" / "Permanent Enrolment Number".
- UGC CBCS fixes grade points but not percentage cut-offs.
- KSU A+ is a range (4.76–5.00) on some sources, a fixed 5.0 on others.
- USI excludes I and O and uses a Luhn mod-N check character (vendor docs only).
- IB SL-points threshold reported inconsistently by secondary sources (9 vs 12).
